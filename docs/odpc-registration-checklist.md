# ODPC Registration Checklist (human task — launch blocker)

Office of the Data Protection Commissioner (Kenya). The app answerable pieces
are built (`apps/compliance`); the steps below are for a human, in order.

## Before applying
- [ ] Finalize the data-controller identity: legal name, physical address,
      one DPO contact (a person, not a role inbox).
- [ ] Decide controller vs processor posture for the SACCO premium tools —
      SACCO admins use the operator dashboards as *their own* processing;
      the app is their tooling, not their agent, unless an agreement says so.
- [ ] Print the evidence pack (all generated by the app):
  1. `apps/compliance` DataMap inventory (models → purposes, lawful bases,
     retention) — staff dashboard, /compliance/
  2. Consent ledger export (04's ConsentEvents) for a sample user
  3. One DSAR ACCESS archive + one DSAR DELETE receipt (run the flows in
     staging first — the delete is real)
  4. Retention sweep output (pings 72 h, sessions 12 h, aged requests 90 d)
  5. `docs/dpia-live-location.md` (the flagship feature's DPIA)
- [ ] Security posture evidence: Prompt 41 hardening (headers, cookie
      flags, secrets-sweep test) + the backup/restore rehearsal note.

## At the ODPC portal
- [ ] Register as data controller; tick the processing categories that
      match the DataMap (marketing comms NO; online identifiers YES —
      sessions/IP throttling; location YES).
- [ ] Describe the purposes in the registration form using the DataMap's
      own wording (keep one vocabulary — the auditor's first ask is that
      the registration and the app agree).
- [ ] Fee payment; note the certificate number in Project_state.md.

## After registration (standing obligations)
- [ ] Annually: review `docs/dpia-live-location.md` + rerun the DSAR drill.
- [ ] Keep the consent ledger export routine (quarterly is sufficient
      evidence hygiene at current scale).
- [ ] Breach runbook: if a location/token incident occurs, PDPS breach
      reporting timelines apply — the 72-h retention cap bounds exposure;
      record the incident + notify per DPA timelines.
- [ ] Any new personal-data field must land in `apps/compliance/inventory.py`
      AND get a DataMap entry — the suite enforces this both directions.
