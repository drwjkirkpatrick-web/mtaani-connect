{% trans "How the journey planner works" %}

{% trans "The plan walks the shared stage graph: consecutive matatu hops on one route, transfers when routes share a stage (with a realistic change-wait), and short labelled WALK legs of at most 300 metres." %}

{% trans "Two sources, kept apart" %}

  • {% trans "Official / seeded route data:" %} {% trans "routes and stages from the 2018 Digital Matatus GTFS seed (badged 'seed') or curated by admins (badged 'official'). These decide where matatus go." %}
  • {% trans "Community-reported conditions:" %} {% trans "rider reports (delays, flooding, closures) weighted and time-expired by the crowd system. Every condition line cites how many riders reported it, when it was first seen and how old it is — and reports older than 2 hours are dropped at read time, never shown as current." %}

{% trans "What the numbers are" %}

  • {% trans "Minutes are honest estimates computed from stage-to-stage distances at one city walking pace — the routes database carries no live speeds, and we do not invent them." %}
  • {% trans "Fares are observed RANGES per leg and for the whole journey — matatu fares move with time and weather, so there is never one official number." %}
  • {% trans "When a stage has no coordinates, its hop carries a flagged default estimate instead of a guessed distance." %}
  • {% trans "When no route connects where you are to where you're going, we say so — no plan is fabricated." %}

{% trans "Reported conditions change which route the planner prefers, but they never silently change the story: the current plan, the usual route and a steer-clear alternative are each shown with their own citations." %}
